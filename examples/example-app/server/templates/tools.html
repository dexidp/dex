Introspection

Asks dex what it thinks of a token. This is the only way to learn that a token has been revoked: a revoked token still has a valid signature.

Local verification

Checks the signature against the issuer's published keys and reads the claims, the way a resource server would. It says nothing about revocation.

UserInfo

Calls the provider's UserInfo endpoint with an access token.

Refresh

Redeems a refresh token for a new set of tokens.
